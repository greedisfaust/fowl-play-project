# Apartment Floor Finish

The Apartment floor finish is generated by `architecture/apartment_floor_builder.gd`.

## Design

- Main Room: warm greige limestone-look porcelain, long rectangular 1.2 m × 0.6 m tiles in a staggered running-bond layout, fine dark grout, subtle per-tile tone variation.
- Hallway: warm walnut planks, approximately 2.4 m long × 0.22 m wide, staggered end joints and narrow dark seams.
- Elevator lobby: deep charcoal stone tiles with a fine bronze perimeter inlay.
- Transitions: narrow bronze strips at the Main Room doorway and elevator lobby opening.

The surface colors are restrained so they complement the Apartment's walnut furniture, charcoal wall treatment, bronze window details, and warm lighting.

## Editor setup

1. Pull the latest commits on `environment/world-building-and-gameplay-loop`.
2. Open `res://world/apartment/apartment.tscn`.
3. Under `Apartment/Environment`, create a `Node3D` named exactly `FloorFinish`.
4. Keep its transform at position (0, 0, 0), rotation (0, 0, 0), scale (1, 1, 1).
5. Attach `res://world/apartment/architecture/apartment_floor_builder.gd` to `FloorFinish`.
6. Let the editor generate the floor finish, then save the Apartment scene.

Expected hierarchy:

```text
Apartment
└── Environment
    ├── Foundation
    │   ├── MainRoomFloor
    │   ├── HallwayFloor
    │   └── ElevatorLobbyFloor
    └── FloorFinish
        └── _GeneratedApartmentFloorFinish
            ├── MainRoom_Limestone_Tile_Floor
            ├── Hallway_Walnut_Plank_Floor
            ├── ElevatorLobby_Dark_Stone_Floor
            └── Bronze_Floor_Transitions
```

## Important: existing foundation is untouched

This script only adds thin decorative MeshInstance3D surfaces slightly above the existing Foundation floors. It does not modify, replace, resize, reposition, or regenerate `MainRoomFloor`, `HallwayFloor`, or `ElevatorLobbyFloor`. It does not add collision; the existing foundation floor collision remains responsible for player and prop support.

Do not attach this builder to `Foundation` or `Architecture`. Attach it to the new sibling `Environment/FloorFinish` at the origin.

## Regeneration and customization

Use the Inspector exports to disable a section, change tile/plank dimensions, adjust colors, or toggle transition details. Toggle `Rebuild Floor` to regenerate. The generated root is replaced on rebuild, so do not put hand-edited content inside `_GeneratedApartmentFloorFinish`.

This is an editor-time decorative finish. It has not yet been parsed or visually validated in the user's Godot editor; inspect the result before making further design adjustments.
