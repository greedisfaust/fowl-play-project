# Apartment Props — First Furniture Collection

This collection is generated by `apartment_furniture_builder.gd`.

## Editor setup

1. Pull the latest commits on `environment/world-building-and-gameplay-loop`.
2. Open `res://world/apartment/apartment.tscn`.
3. Under `Apartment/Environment`, create a `Node3D` named exactly `Props` if it does not already exist.
4. Keep `Props` at local position (0, 0, 0), rotation (0, 0, 0), and scale (1, 1, 1).
5. Attach `res://world/apartment/props/apartment_furniture_builder.gd` to `Props`.
6. Let the editor finish generating. The generated collection appears under `Props/_GeneratedApartmentProps`.
7. Save the Apartment scene.

Do not attach the builder to the Apartment root or to Architecture. Its generated positions are authored in Apartment-root coordinates, so the Props node must remain at the Apartment origin.

## First collection contents

- Living room: detailed sectional sofa and chaise, layered area rug, stone-and-walnut coffee table, media console and television, two side tables, arc floor lamp.
- Dining area: walnut dining table with stone inset, four upholstered chairs, dining sideboard.
- Storage and decor: open walnut display shelving, three planters with foliage, framed abstract artwork.
- Carryable props: ceramic vase, coaster set, coffee cup, decorative books, centerpiece bowl.

## Physics and interaction

- Fixed furniture uses simplified StaticBody3D collision boxes. Decorative trim and individual visual details do not each receive their own collision.
- Carryable objects are instances of the existing `res://props/base_prop.tscn`, not replacement rigid bodies.
- Carryable objects use individual, named Prop instances, the existing Interactable child, and one of the Apartment PropProfile resources in `profiles/`.
- Profiles currently use the properties supported by the existing PropProfile script: weight class, pickup permission, throwable permission, and size class.
- The five loose objects are deliberately small/light or medium/light props. Their current throw settings are defined by their assigned profile.

## Regeneration

The builder generates editor-owned nodes beneath `_GeneratedApartmentProps`. To regenerate after changing exported values, toggle `Rebuild Props` in the Inspector. The old generated root is replaced; manually edited content should not be placed inside that generated root.

The builder is editor-only and does not generate furniture at runtime.

## Important validation

This is the first visual blockout-quality furniture pass, with layered materials and named subcomponents. Please inspect it in Godot before we add more prop batches. Check that the dining area and shelving do not overlap your preferred walking routes, and confirm the carryable props are focused/grabbable. No Godot editor parse or in-game playtest has been run by the assistant.
